# STAYLE — متجر القمصان الرجالية
متجر عربي RTL مخصص لموديلات القمصان الرجالية، مع اختيار اللون والمقاس وسلة طلب عبر واتساب.

## التشغيل
```bash
npm install
npm run dev
```
افتح http://localhost:3000

## الموديلات المعروضة
النور اعتكاف، الدفة، الأصيل، البدر، الجاسم، الفاخر، الشياكة، النخبة، الحرمين، ديور المكرمش، بوس.

## تنبيه قبل البيع الحقيقي
الأسعار والصور والكميات المعروضة بيانات تجريبية قابلة للتعديل. الصور ليست صوراً مؤكدة للمنتجات الأصلية. البيانات تحفظ في LocalStorage على المتصفح فقط؛ لا توجد قاعدة بيانات مشتركة أو مصادقة إدارية أو تسجيل طلبات مركزي أو خصم مخزون آمن حتى الآن. يلزم استكمال PostgreSQL/Prisma وAPI آمن ونظام طلبات ومخزون حسب كل مقاس ولون قبل استقبال الطلبات الفعلية.
