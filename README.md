# ستايل · STAYLE — متجر قمصان رجالية لرمضان

متجر عربي (RTL) لقمصان الرجال الذين يصلّون في المساجد، بصفحة واحدة من HTML وCSS وجافاسكربت خالص (بدون أي إطار).

## الميزات
- عرض دوّار ثلاثي الأبعاد لست إطلالات (تشغيل تلقائي كل 5 ثوانٍ، شريط تقدم، أسهم، إيقاف، سحب، لوحة مفاتيح).
- نافذة «عرض الإطلالة» بنقاط تفاصيل (الياقة، الكم، القماش).
- لوحة «في هذه الإطلالة»: اختيار اللون والمقاس، وخصم 10٪ عند إضافة الإطلالة كاملة.
- كتالوج 16 قميصاً مع تصفية حسب القصة، ودليل للقصات.
- حقيبة محفوظة في المتصفح، وإرسال الطلب عبر واتساب.

## التشغيل
افتح `index.html` مباشرة، أو: `python3 -m http.server` ثم http://localhost:8000

## قبل البيع الحقيقي
- غيّر رقم واتساب في `data.js` (`WHATSAPP`).
- الأسعار والألوان تجريبية، والقمصان رسومات SVG توضيحية؛ استبدلها بصور منتجاتك (`S.art` في `data.js`).
- الحقيبة في LocalStorage فقط؛ لا توجد قاعدة بيانات أو مخزون مركزي.
