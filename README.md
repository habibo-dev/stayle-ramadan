# STAYLE — متجر الأزياء المحتشمة
واجهة متجر عربية RTL بتصميم تحريري راقٍ ولوحة إدارة أولية.

## التشغيل
```bash
npm install
npm run dev
```
افتح http://localhost:3000

## الموجود حالياً
- المتجر: تصنيفات وبحث وتفاصيل المنتجات واختيار اللون والمقاس وسلة مشتريات.
- الطلب: تجهيز الطلب وإرساله عبر واتساب (الدفع عند الاستلام).
- /admin: لوحة أولية لإضافة المنتجات ومتابعة وتعديل كميات المخزون حسب اللون.

## مهم قبل البيع الحقيقي
هذه نسخة MVP للواجهة والتجربة فقط. البيانات محفوظة في LocalStorage على نفس المتصفح وليست قاعدة بيانات مشتركة. لا يوجد حتى الآن تسجيل دخول إداري أو خادم أو طلبات مركزية أو خصم مخزون آمن متعدد المستخدمين. المرحلة التالية المطلوبة للإطلاق: PostgreSQL/Neon + Prisma، مصادقة، API آمن، مخزون مستقل لكل لون ومقاس/SKU، سجل حركات، تأكيد طلبات يمنع الخصم المكرر، إلغاء واسترجاع، ومحاسبة تكلفة الشراء والمصاريف.

استبدل صور العرض التجريبية بصور المنتجات الفعلية، وحدد رقم واتساب وتكاليف التوصيل وسياسة الاستبدال قبل النشر.
